## 2. 数据库设计

### 2.1 实体关系图（ERD）

```
用户(User) ────┬─── 学习待办(StudyPlan) [1:N]
              ├─── 考试时间(ExamTime) [1:N]
              ├─── 学习动态(StudyStatus) [1:N]
              ├─── 每日状态(EverydayStatus) [1:1]
              ├─── 评论(Comment) [1:N]
              ├─── 点赞记录(LikeRecord) [N:M] ──── 学习动态(StudyStatus)
              ├─── 举报(Report) [1:N]
              └─── 自习室(StudyRoom) [1:N]

自习室(StudyRoom) ──── 分类(Category) [N:1]
管理员(Admin) ──── 公告(Notice) [1:N]
```

### 2.2 核心表结构设计

#### 2.2.1 用户表 (user)
```sql
CREATE TABLE user (
    id INT PRIMARY KEY AUTO_INCREMENT,
    userName VARCHAR(255) NOT NULL,
    cellPhone VARCHAR(20) NOT NULL UNIQUE,
    userPassword VARCHAR(255) NOT NULL DEFAULT 'psw',
    userAvatar VARCHAR(255) DEFAULT NULL,
    gender INT NOT NULL DEFAULT 0,
    exp BIGINT NOT NULL DEFAULT 0,
    rank INT NOT NULL DEFAULT 1,
    studyTime BIGINT NOT NULL DEFAULT 0,
    status INT NOT NULL DEFAULT 0,
    banDay INT NOT NULL DEFAULT 0,
    createTime DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 2.2.2 学习动态表 (study_status)
```sql
CREATE TABLE study_status (
    id INT PRIMARY KEY AUTO_INCREMENT,
    userId INT NOT NULL,
    userName VARCHAR(255) NOT NULL,
    userAvatar VARCHAR(255) DEFAULT NULL,
    content TEXT NOT NULL,
    firstPhoto VARCHAR(255) DEFAULT NULL,
    secondPhoto VARCHAR(255) DEFAULT NULL,
    thirdPhoto VARCHAR(255) DEFAULT NULL,
    transmitCount INT DEFAULT 0,
    commentCount INT DEFAULT 0,
    likeCount INT DEFAULT 0,
    isLike TINYINT(1) DEFAULT 0,
    createTime DATETIME NOT NULL
);
```

#### 2.2.3 点赞记录表 (like_record) - 多对多关系实现
```sql
CREATE TABLE like_record (
    id INT PRIMARY KEY AUTO_INCREMENT,
    userId INT NOT NULL,
    studyStatusId INT NOT NULL,
    createTime DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY unique_like (userId, studyStatusId)
);
```

### 2.3 索引设计

| 表名 | 索引字段 | 索引类型 | 用途 |
|------|----------|----------|------|
| user | cellPhone | 唯一索引 | 登录验证 |
| user | studyTime | 普通索引 | 排行榜查询 |
| study_status | userId | 普通索引 | 用户动态查询 |
| study_status | createTime | 普通索引 | 时间排序 |
| like_record | (userId, studyStatusId) | 唯一索引 | 防止重复点赞 |

### 4.2 缓存失效策略

| 缓存类型 | 失效时间 | 更新策略 |
|----------|----------|----------|
| 用户信息 | 30分钟 | 用户信息更新时清除 |
| 验证码 | 5分钟 | 使用后立即清除 |
| 动态热度 | 永久 | 定时任务更新 |
| 公告信息 | 1小时 | 公告更新时清除 |
