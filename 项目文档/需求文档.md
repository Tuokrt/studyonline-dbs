# StudyOnline 在线学习平台需求文档

## 项目概述

StudyOnline 是一个功能完善的在线学习社交平台，旨在为用户提供学习管理、社交互动、自习监督等一体化服务。平台采用Spring Boot + MyBatis + JSP技术栈开发，支持用户注册登录、学习计划管理、备考日历、学习动态分享、自习室管理等功能。

## 项目技术架构

- **后端框架**: Spring Boot 2.x
- **持久层**: MyBatis
- **视图层**: JSP + LayUI
- **数据库**: MySQL 8.0
- **缓存**: Redis
- **定时任务**: Spring Scheduling
- **WebSocket**: 实时通信支持

## 核心功能模块

### 1. 用户管理模块

#### 1.1 用户注册与登录
- 手机号注册与登录
- 用户信息完善（用户名、头像、性别等）
- 密码修改与找回
- 用户等级与经验值系统

#### 1.2 个人中心
- 个人信息管理
- 头像上传与更新
- 密码修改
- 手机号更换

#### 1.3 用户状态管理
- 每日打卡系统
- 学习时长统计
- 经验值积累
- 等级提升机制

### 2. 学习管理模块

#### 2.1 学习待办管理
- 添加学习任务
- 查看待办列表（分页显示）
- 修改待办内容
- 删除待办任务
- 标记任务完成状态
- 未完成任务统计

#### 2.2 备考日历管理
- 添加考试计划
- 查看考试日历（分页显示）
- 修改考试信息
- 删除考试计划
- 即将到来的考试提醒

### 3. 学习动态模块

#### 3.1 动态发布与查看
- 发布学习动态（支持文字和最多3张图片）
- 查看所有用户动态（分页显示）
- 查看个人动态
- 动态删除功能

#### 3.2 社交互动功能
- 点赞功能（支持取消）
- 评论功能（分页显示）
- 转发功能
- 评论统计与显示

#### 3.3 动态热度系统
- 基于Redis的ZSet实现热度排名
- 热度衰减算法（Lua脚本）
- 热门动态展示

### 4. 自习室模块

#### 4.1 自习室管理
- 创建自习室（需审核）
- 加入自习室
- 自习室信息管理
- 自习室状态管理（开放/关闭）

#### 4.2 自习功能
- 个人自习计时器
- 自习室学习监督
- 学习时长统计
- 学习效率分析

### 5. 管理员模块

#### 5.1 用户管理
- 用户信息查看
- 用户封禁管理
- 用户数据统计

#### 5.2 内容管理
- 学习动态审核
- 评论管理
- 举报处理
- 自习室审核

#### 5.3 系统管理
- 公告发布
- 系统数据统计
- 学习排行榜

### 6. 系统功能模块

#### 6.1 缓存系统
- Redis缓存用户信息
- 动态热度缓存
- 公告缓存
- 学习排行榜缓存

#### 6.2 定时任务
- 每日打卡状态重置
- 用户封禁天数自动减少
- 动态热度衰减计算

#### 6.3 实时通信
- WebSocket支持实时消息
- 在线状态管理
- 实时通知功能

## 数据库设计

### 核心数据表

1. **用户表 (user)**
   - 用户基本信息
   - 学习统计数据
   - 账号状态管理

2. **学习待办表 (study_plan)**
   - 待办内容
   - 完成状态
   - 创建时间

3. **备考日历表 (exam_time)**
   - 考试名称
   - 考试时间
   - 用户关联

4. **学习动态表 (study_status)**
   - 动态内容
   - 图片附件
   - 互动统计（点赞、评论、转发）

5. **点赞记录表 (like_record)**
   - 用户与动态关联
   - 唯一约束防止重复点赞

6. **评论表 (comment)**
   - 评论内容
   - 用户与动态关联
   - 评论时间

7. **自习室表 (study_room)**
   - 自习室信息
   - 审核状态
   - 开放状态

8. **举报表 (report)**
   - 举报内容
   - 处理状态
   - 举报类型
